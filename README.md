# 午前2くん

IPA 高度試験 科目A-2（旧 午前Ⅱ）の過去問ドリル。スマホ向けの静的サイト（PWA）で、ビルドは不要。

- 収録：ITストラテジスト試験 午前Ⅱ 8回分（令和7〜3年度 春期、令和元年度・平成30年度・平成29年度 秋期）200問。令和2年度は ST の午前Ⅱ問題が IPA で公開されていないため収録していない。
- 本番モード：25問・40分・採点（基準点60%）。年度指定、または全年度からランダム25問。
- 1問ずつモード：解答するとすぐ正誤と正解を表示。
- 間違いノート：間違えた問題だけを出題。2回続けて正解すると卒業。
- 成績：全体と年度ごとの正答率、本番の履歴。記録は端末の localStorage のみ。

## 出典

問題と正解は、独立行政法人情報処理推進機構（IPA）が公表している過去問題（問題冊子・解答例）を使用している。各問題に「出典：令和7年度 春期 ITストラテジスト試験 午前Ⅱ 問1」の形式で年度・期・試験区分・時間区分・問番号を表示している。

## データの作り方

IPA の問題冊子 PDF は画像のみで、文字データを含まない。そこで次の手順で作成した（PDF は `raw/` に置き、リポジトリには含めない）。

1. `node tools/crop.mjs`：問題冊子の各ページから「問N」の行を検出し、1問ずつ画像に切り出す（各回25問であることを確認）。
2. `node tools/answers.mjs`：解答例 PDF の文字データから正解を抽出する。正解は解答例 PDF 以外から取らない。
3. 文字起こし：切り出した画像から、2つの独立した作業で問題文と選択肢を書き起こし、差分を照合した。さらに高解像度の画像と1字ずつ校正した。図表を含む問題と、選択肢が表になっている問題は、原文の画像をそのまま表示する。テキストで表示する問題でも「原文の画像を見る」で原本を確認できる。
4. `node tools/images.mjs`：表示用の WebP 画像を作成する。
5. `node tools/build.mjs`：`data/questions.json` を生成し、自動チェックを行う（各回25問、選択肢が4つ、正解がア〜エ、空欄・文字化け・想定外の文字、校正の指摘）。問題があれば `needs_review: true` とし、出題から除外する。
6. `node tools/sw.mjs`：Service Worker を生成する。キャッシュ名に内容のハッシュを含めるため、更新すると古いキャッシュは削除される。

確認：`node tests/e2e.mjs`（幅 390px のヘッドレス Chromium で、本番・間違いノート・成績の保持・オフライン動作を確認する）。
